# 🎓 EduPilot - نظام الرادار الاستباقي

**مشروع هاكاثون جامعة الباحة 2026**

نظام ذكي لمتابعة الطلاب الأكاديمية يتميز بـ **الرادار الاستباقي** للكشف المبكر عن المواد السنوية الحرجة التي قد تؤخر التخرج.

## ✨ المميزات

- 🔐 **نظام دخول كامل** - تسجيل ودخول حقيقي عبر Supabase Auth
- 📡 **الرادار الاستباقي** - كشف ذكي للمواد السنوية الحرجة (مثل تراكيب البيانات)
- 📊 **لوحة تحكم تفاعلية** - عرض المواد مع تصنيفها (سنوية/فصلية)
- 🎨 **تصميم عصري** - Tailwind CSS + خط Cairo + RTL
- ⚡ **تجربة مستخدم سلسة** - Loading states ورسائل خطأ بالعربي

## 🚀 التشغيل

```bash
# تثبيت الحزم
npm install

# تشغيل المشروع
npm run dev
```

## 🔗 الربط بـ Supabase

- **URL:** https://qhynlkmtzsbyqsgqkteu.supabase.co
- **جدول courses:** يجب إنشاؤه في Supabase مع الأعمدة:
  - `id` (bigint, primary key)
  - `name` (text)
  - `is_annual` (boolean)
  - `semester` (text)
  - `code` (text)
